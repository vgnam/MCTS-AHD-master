IMPORTANT IMPLEMENTATION DETAILS:
1. Input Type: 'unvisited_nodes' is a Python SET.
2. Requirement: You CANNOT access a set by index (e.g., unvisited_nodes[0]) or use it directly in random.choices().
3. Solution: You MUST convert it to a list first. Example:

   # Then perform operations on 'candidates'
